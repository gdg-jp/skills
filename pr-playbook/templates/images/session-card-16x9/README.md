# session-card-16x9

セッション紹介（横）（X）。1600×900 px（2x で描画）。design 方式の既定の型は `examples/design/html/x-session-card-16x9.html`。

- 必須スロット: `sessionTitle`, `speakerName`, `speakerRole`
- 任意: `eventName`, `speakerImageUrl`, `track`, `time`
- layoutVars: `titleScale`（0.8〜1.2）、`align`（left / center）、`emphasis`（強調する語、3 つまで）

タイムラインの縮小表示で題と名前が読めること。写真が無いときは写真の型を使わない
