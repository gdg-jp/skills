# デザインの事例

`guides/design.md` の根拠。チャプターのデザイナーが Figma で作った 3 イベントの制作物を測り、キット（判断と値）として書き出した。
写真と人名は入れない（このリポジトリは公開）。実物の画像は pr アプリの「デザインの参考」（チャプターごとの R2）にあり、
`asset` ジョブに添付される。

- `kits/devfest-kansai-2026.json` — 公式 DevFest の語彙を大阪の青で。ブレースのロックアップ、3 段の顔、角丸写真とノッチ
- `kits/innovative-crosstalk-2026.json` — 夏祭りの夜。濃紺と朱、グラデーションのロゴ、クリームのパネル、卵型の写真
- `kits/io-extended-osaka-2026.json` — 公式 I/O に合わせた黒と虹のグラデーション。白い帯の見出し
- `html/` — キットどおりに HTML で組み直した型（文言はダミー）。`pr-asset` の出発点であり、描画器のテスト入力

新しいイベントのキットを足すときは、同じ形の JSON を置き、`why` を必ず書く。
