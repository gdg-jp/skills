# 広報手段

## 手段の一覧
<!-- tips: 18 -->

SNS に限らず、次の手段を毎回検討する（`constants.channelCatalog`）。

- SNS 投稿（X、Instagram）と SNS 広告
- フライヤーの配布と掲示
- 技術イベントやカンファレンスでの LT やフライヤー配布
- 技術イベントに参加し、参加者と知り合ってフォローしてもらい紹介する
- 各 GDG チャプターの Discord サーバーでの告知
- 大学・研究室・会社への紹介（まとめて来てもらう）
- 友達を誘う
- コネクションのある技術コミュニティや技術サークルへの声かけ、LT 登壇の依頼
- フォロワーの多いスピーカーの招待
- ノベルティ（リファラル特典、交換コード特典、SNS フォロー特典）
- 特定の層に刺さる企画

この一覧は既定値で、キャンペーンごとに足してよい（LINE、ニュースアプリ広告、プレスリリースなど）。

## 媒体の優先順位
<!-- tips: 25 -->

connpass → X → Instagram → フライヤー → Luma / Techplay / Findy。
