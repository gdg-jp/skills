# GDG Japan Skills

Agent skills for working with GDG Japan services, tools, content, and visual assets.

## Installation

Choose and install skills interactively:

```sh
npx skills add gdg-jp/skills
```

Install every skill for every supported agent:

```sh
npx skills add gdg-jp/skills --all
```

Install a specific skill:

```sh
npx skills add gdg-jp/skills --skill gdg-accounts
```

## Skills

- **connpass-decent-description** — Structure and style connpass event descriptions that convert.
- **connpass-session-list-image** — Create session-list graphics with portraits and keyword emphasis.
- **connpass-syntax** — Write connpass group and event descriptions with supported formatting.
- **connpass-timetable-image** — Create desktop and mobile event timetable graphics.
- **pr-playbook** — The source of truth for GDG event PR judgment: rules, guides, examples, and the draft checker.
- **pr-copy** — Turn a brief's meta-themes into titles and main copy, per medium and audience.
- **pr-x-post** — Write X and Instagram posts: fold position, image vs OGP, timing, and staff / speaker asks.
- **pr-connpass-page** — Build a connpass event page with a 3-line summary, decorated sections, and images.
- **pr-connpass-mail** — Write short, decorated connpass messages at the right time.
- **pr-asset** — Design an event's images (thumbnail, session and speaker cards, countdowns, ads, Instagram) in HTML by the event's design kit, render, look and self-review (`pr-playbook/guides/design.md`).
- **pr-plan** — Plan channels, budget, ad flights, schedule, reminders, pre-events, swag, and the survey.
- **pr-assist** — The event's assistant on pr.gdgs.jp: read pasted pages, shared Google files and images, update the brief, and offer next steps.
- **gdg-accounts** — Manage GDG Accounts OIDC clients with the `gdg` CLI.
- **gdg-connpass** — Manage connpass groups, events, surveys, and organizer workflows.
- **gdg-design** — Create and review visuals that follow the GDG brand system.
- **gdg-img** — Manage images hosted on img.gdgs.jp with the `gdg` CLI.
- **gdg-sns** — Manage scheduled X posts, media, accounts, and contributors.
- **gdg-tinyurl** — Manage short links, domains, campaigns, and analytics on url.gdgs.jp.
- **gdg-wiki** — Edit, synchronize, ingest, and validate GDG Wiki content.
- **gdgjp-third-party-oidc** — Integrate third-party applications with GDG Japan Accounts.
